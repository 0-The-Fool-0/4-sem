# Учёт сотрудников и формирование отчётов на C++

[English version](README.md)

Учебный проект на C++ для Windows, демонстрирующий работу с бинарными записями сотрудников, отдельными консольными утилитами, запуском дочерних процессов и формированием отчётов.

## Компоненты

| Файл | Назначение |
|---|---|
| `Main.cpp` | Координирует сценарий и запускает вспомогательные исполняемые файлы. |
| `Creator.cpp` | Вспомогательная программа для создания бинарного файла записей сотрудников. |
| `Reporter.cpp` | Читает бинарные записи и формирует отчёт по отработанным часам и рассчитанной оплате. |
| `employee.h`, `employee.cpp` | Структура сотрудника и функции чтения/обработки файлов. |
| `test.cpp` | Тесты GoogleTest для формирования отчёта и обработки ошибок. |

## Сборка и тесты

Нужны Windows, компилятор с поддержкой C++20, CMake и доступ в интернет для загрузки GoogleTest текущей конфигурацией проекта.

```powershell
cmake -S . -B build
cmake --build build --config Debug
ctest --test-dir build -C Debug --output-on-failure
```

Команды основаны на текущем CMake-файле; в рамках этого обновления они не запускались. Используется Windows API `CreateProcessA`, поэтому пример не является кроссплатформенным.

## Замечания по реализации

- `Creator.cpp` выводит запрос данных сотрудника; нужно убедиться, что текущая реализация действительно считывает и проверяет введённые поля до записи.
- CMake загружает GoogleTest из ветки `main`, а не из закреплённой версии, поэтому сборка не полностью воспроизводима.
- Это учебная работа, а не готовая система обработки кадровых данных. Перед использованием необходимо проверить валидацию входа и обработку ошибок бинарных файлов.
